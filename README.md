## v0.3.52 — 小説TXTに混入するページ指定UIを全位置で除去

- pictBLandのページャーが「頁指定1 / 3頁2 / 3頁3 / 3頁」のような文字列として本文DOMに混ざるケースに対応。
- ページ冒頭だけでなく、ページ下部・途中に出た場合もTXT化の最終整形で除去します。
- 「本文 1 / 3頁」のページ番号行や、複数の「1 / 3頁 2 / 3頁…」だけで構成されたページUIも対象。通常の小説本文中の単独の「1/3」などは除去しません。
- paginated / continuous / structured-pages のどの抽出経路でも最終的に同じ除去処理を通します。
- TXT編集画面の固定表示バージョンがv0.3.46のままだったため、v0.3.52へ更新しました。

## v0.3.51 — 各保存条件を新着15作品に限定・全作品を新着順で処理

- 「まとめて新着」は各保存検索条件から新しい順に最大15作品だけ取得します。8条件なら取得候補は最大120作品で、同じ作品が複数条件に入る場合は重複を統合するため実数はさらに減ります。
- 全条件の候補を集めた後、除外タグの追加確認が必要な作品は保存条件の順ではなく、作品全体の新着順で処理します。
- 「さらに表示」はすでに集めた候補の表示件数だけ増やし、各保存条件の16件目以降を追加取得しません。「古い作品を読み込む」はこの新着ビューでは無効化します。
- v0.3.50の検索結果タグによる即時除外判定は維持。検索結果にタグが無い作品だけ詳細確認します。
- 通信間隔2.2秒・429保護は維持します。

## v0.3.50 — 検索結果のタグで除外判定を即時完了

- v0.3.49では、除外タグが設定されていると検索結果カードにタグが見えている作品まで詳細ページへ再アクセスしていました。2.2秒の通信間隔では50件だけでも最低約110秒、数百件では十数分かかり得るため現実的ではありませんでした。
- 検索結果カードから実際のタグリンクを取得できた作品は、そのタグ情報で除外判定済みとします。除外タグに一致すれば表示せず、一致しなければ詳細ページ待ちなしで表示します。
- 検索結果からタグを取得できなかった作品だけ詳細ページを確認します。詳細ページでもタグを取得できない作品は安全側で非表示のままにします。
- 保存検索の処理順は引き続き上から下、画面の作品表示順は全体の新着順です。
- 2.2秒通信間隔・429保護は維持し、アクセス頻度は増やしません。

## v0.3.49 — まとめて新着を保存検索の上から順に処理・除外タグ確認を前倒し

- 「まとめて新着」の検索処理を、保存検索の並び順どおり上から下へ変更。1つ目の検索を必要件数まで取得してから2つ目へ進みます。
- 全保存検索の取得完了を待たず、各検索で作品が取れた時点から除外タグ確認の詳細取得を開始。詳細確認の待ち行列も保存検索の上位を優先します。
- 作品詳細HTMLからタグを取得できた場合は、その時点で除外判定を確定し、キャプション取得だけのための追加iframe描画待ちを省略します。タグが取得できない場合は従来どおり描画フォールバックを使います。
- pictBLandへの通信間隔2.2秒と429保護は維持。アクセス頻度を上げず、処理順と不要な待機を減らして体感速度を改善します。
- 画面の最終表示順は従来どおり作品の新着順です。処理順だけが保存検索の上から下になります。
- 実機Safariでの通信・表示速度は更新後に確認が必要です。

## v0.3.48 — 「まとめて新着」除外タグの表示前検証

- 除外タグがある場合、作品詳細からタグを確認できた作品だけを順次表示。確認前はタイトルやサムネイルを表示しません。
- 検索一覧に除外タグがある作品は詳細取得せず除外。詳細が取れなかった作品は非表示のまま「タグ確認不可」の件数に含めます。
- 除外タグが未設定ならこれまでどおり即時表示。画面に出したカードは再利用してちらつきを軽減します。
- 詳細確認待ちのため表示が遅くなる場合があります。検索の通信間隔・アクセス制限対策・Cloud同期は変更しません。
- 実際のPC・スマホ環境では未検証です。

## v0.3.47 — 保存検索「まとめて新着」除外タグのクラウド同期対応

- 除外タグの変更時だけ更新日時を記録し、Niji Cloud Backupに変更通知を送信します。
- Niji Cloud側からの反映時、開いている「まとめて新着」のタグ表示とフィルタを自動更新します。
- 表示までのタグ確認方法は従来のままです。既存の作品収集・除外ロジックは変更していません。

# pictbland-toolkit

pictBLand向けの個人用ツール集です。

- `index.html` — 印刷PDFから本文を抽出してTXT化するブラウザツール
- `PictBLand_Novel_Tools.user.js` — pictBLand小説ページ用Userscript
- `PictBLand_Novel_Tools.meta.js` — Userscript更新確認用メタデータ

PDF→TXTツールはPDFをブラウザ内で処理し、PDFファイル自体をサーバーへ送信しません。
