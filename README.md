## v0.3.55 — 本物の「フォロ限」を復帰しつつ非表示テンプレートを除外

- v0.3.54では誤表示対策を強くしすぎ、badge/chip/status等に実際の公開範囲が出る本物のフォロ限まで拾えなくなっていました。
- badge/chip/status等から「フォロ限」「鍵付」などを再び取得します。ただし hidden / aria-hidden / inert / display:none / visibility:hidden / opacity:0 / hidden系クラス / template要素は除外します。
- 実際のページDOM上では getComputedStyle と getClientRects も使い、描画されていないバッジを除外します。
- 通常タグのリンク内にある「フォロ限」は公開範囲バッジとして扱いません。
- 詳細ページ側で公開範囲が取れなかった場合も、検索カードで確認済みの表示は消さず保持します。

## v0.3.54 — 「フォロ限」誤表示をさらに保守的に修正

- 前版でも誤表示が残ったため、まとめて新着の公開範囲判定をさらに絞りました。
- badge/chip/status等の汎用要素からは R18/R18G だけを取得し、「フォロ限」「鍵付」「相互のみ」等は取得しません。
- 「フォロ限」等は class/data属性に visibility/access/restrict/locked/limited/permission 等が明示された公開範囲専用要素からだけ取得します。
- カード内の短い span/small/strong/em を総当たりするフォールバックを廃止しました。非表示テンプレートや共通UIの「フォロワー限定公開作品」を拾う経路を遮断します。
- 詳細ページを確認した場合は、以前の公開範囲表示を足し続けず、詳細側で確認できた公開範囲へ置き換えます。
- 確認できない公開範囲は表示しない方針です。誤って「フォロ限」と表示するより、ラベルなしを優先します。

## v0.3.53 — 「まとめて新着」の公開範囲バッジ誤判定を修正

- 「フォロ限」等の判定で、作品タイトルより前のカード本文や詳細ページ全体を読む方式を廃止。隣の作品・共通UI・説明文に「フォロワー限定」があるだけで誤表示される経路をなくしました。
- 公開範囲は、badge/chip/visibility/access/status等の明示的な短い要素、または全文が既知の公開範囲ラベルだけで構成された短いspan等からのみ取得します。
- 詳細ページでは document.body 全体ではなく、main/article等の作品詳細領域だけを対象にします。
- 「フォロ限だけど〜」のような本文・説明文、通常タグ、長い文章は公開範囲バッジとして扱いません。
- R18/R18G、鍵付、相互のみ、リスト限、マイ限、期間限定、全体公開も同じ厳密判定に統一しました。

## v0.3.52 — 小説TXTに混入するページ指定UIを全位置で除去

- pictBLandのページャーが「頁指定1 / 3頁2 / 3頁3 / 3頁」のような文字列として本文DOMに混ざるケースに対応。
- ページ冒頭だけでなく、ページ下部・途中に出た場合もTXT化の最終整形で除去します。
- 「本文 1 / 3頁」のページ番号行や、複数の「1 / 3頁 2 / 3頁…」だけで構成されたページUIも対象。通常の小説本文中の単独の「1/3」などは除去しません。
- paginated / continuous / structured-pages のどの抽出経路でも最終的に同じ除去処理を通します。
- TXT編集画面の固定表示バージョンがv0.3.46のままだったため、v0.3.52へ更新しました。

## v0.3.51 — 各保存条件を新着15作品に限定・全作品を新着順で処理

- 「まとめて新着」は各保存検索条件から新しい順に最大15作品だけ取得します。8条件なら取得候補は最大120作品で、同じ作品が複数条件に入る場合は重複を統合するため実数はさらに減ります。
- 全条件の候補を集めた後、除外タグの追加確認が必要な作品は保存条件の順ではなく、作品全体の新着順で処理します。
- 「さらに表示」はすでに集めた候補の表示件数だけ増やし、各保存条件の16件目以降を追加取得しません。「古い作品を読み込む」はこの新着ビューでは無効化します。
- v0.3.50の検索結果タグによる即時除外判定は維持。検索結果にタグが無い作品だけ詳細確認します。

## v0.3.50 — 検索結果のタグで除外判定を即時完了

- 検索結果からタグを取得できなかった作品だけ詳細ページを確認します。詳細ページでもタグを取得できない作品は安全側で非表示のままにします。

# pictbland-toolkit

pictBLand向けの個人用ツール集です。

- `index.html` — 印刷PDFから本文を抽出してTXT化するブラウザツール
- `PictBLand_Novel_Tools.user.js` — pictBLand小説ページ用Userscript
- `PictBLand_Novel_Tools.meta.js` — Userscript更新確認用メタデータ

PDF→TXTツールはPDFをブラウザ内で処理し、PDFファイル自体をサーバーへ送信しません。
